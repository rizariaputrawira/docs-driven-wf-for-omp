# Retrospective

1. Inspect the named or current session evidence.
2. Rank concrete recurring friction in navigation, checks, standards, instructions, and tool use. Cite the observed failure and propose the smallest verifiable guardrail.
3. Recommend changes rather than mutating settings or docs unless implementation was requested.
4. If session evidence is unavailable, state exactly what is missing; do not invent failures.
