All local procedures are modified adaptations. The explicit audit boundary, source/control depth, coverage gaps, independent challenge/refutation, meaningful boundary impact and smallest invariant-enforcing fix are retained. OMP native permissions/current task interfaces govern dispatch; Main alone owns records, while security-reviewers never edit, execute, network or delegate. Original authored shared contract owns exact candidate/disposition fields, phase terminal completeness and effective-definition provenance. Complete independent source impact proof can confirm a source-visible issue without falsely claiming runtime exploitation. Decisive runtime/model/deployment facts remain needs-validation. Only separately authorized execution with demonstrated containment and trusted observed executor evidence can support authorized-local.

Removed: universal six-phase engine; research/general role aliases; fixed four-agent reconnaissance and wave/profile/fleet/cost-budget machinery; report forest under home; new run database/JSON ledgers; scratch-file/artifact orchestration code and literal promotion engine; Node validators/report-schema dependency; forced local reproduction for every source confirmation; hunter confirmation/severity/confidence fields; mandatory second record-verifier phase for every unchanged record; shell commands, target executables, installs, automatic writes/commits/provider directives. Native output shape never substitutes for semantic proof or role provenance. This does not relax execution safety: reviewers remain source-only; runtime validation is a separate authorized executor boundary, not a skill capability.

Only the seven listed companion/reference texts and core SKILL are adapted. Other upstream native/web/client/cloud/protocol/data/mobile companion bodies and scripts are not redistributed or linked as if installed. Their real trust boundaries remain eligible under the selected ordinary source-tracing mechanism; unavailable specialist facts are coverage gaps, not blanket safety assumptions. Cross-links to intake/change review load each owner rather than duplicate procedures/notices. No source claim asserts a deployed exploit, sandbox guarantee, whole-codebase completion or installed OMP compatibility. Validation requires the shared disposition, terminal-acceptance and runtime-evidence sections instead of repeating their rules; the local reviewer non-execution guard remains.
