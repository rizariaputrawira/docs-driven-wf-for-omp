# Writing for Agents

Write guidance that is easy to discover, follow, and verify.

1. Keep skill descriptions as concise trigger pointers; put procedure in the body.
2. Order actionable steps in execution order and give them observable completion criteria.
3. Move branch-specific or detailed reference material behind links instead of expanding the core procedure.
4. Keep a single source of truth; link shared guidance rather than duplicating it.
5. Remove no-op, stale, conflicting, and redundant text.
6. Check that examples and tool names are valid for OMP and do not conflict with its higher-priority rules.
